# RASFF-notifications-extractor
This script extracts notifications from the RASFF website and then generates summaries using a local LLM model.
It can be useful for generating real-time summaries of long notifications in just a few seconds.
Stack: Python, Ollama, DeepSeek-R1 14B;
# Installation:
To proceed with the installation, you must have Ollama with your chosen local LLM model installed. To change the model, open the `summerizer.py` file and replace the model name with the one you selected. Next, install Pathlib and run `main.py`.
